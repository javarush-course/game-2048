# 2048 с таблицей рекордов

Головоломка 2048 в браузере и общая таблица рекордов: сыграйте с коллегами в обеденный перерыв и узнайте, кто соберёт больше очков. Плитки сдвигаются стрелками на клавиатуре или свайпом, одинаковые числа складываются. После партии впишите имя — результат попадёт в таблицу.

Проект состоит из трёх частей:

- `web` — страница игры, её отдаёт веб-сервер nginx;
- `scores` — сервер рекордов на Node.js: принимает очки после партии и отдаёт лучшие;
- `redis` — хранилище рекордов Redis, с ним работает только `scores`.

## Запуск через Docker

### Требования

- Docker Desktop (на Linux — Docker Engine с Docker Compose);
- 1 ГБ свободной памяти.

### Запуск

Выполните в папке проекта `docker compose up` и откройте в браузере http://localhost:8080

Чтобы терминал остался свободен, запускайте проект в фоне: `docker compose up -d`.

### Остановка

Остановить проект и убрать его контейнеры — `docker compose down` в папке проекта.

Рекорды хранятся внутри контейнера `redis`. После остановки кнопкой Stop в Docker Desktop или командой `docker compose stop` таблица останется до следующего запуска, а после `docker compose down` начнётся заново.

## Запуск без Docker

1. Установите Node.js 24 или новее.
2. Поставьте Redis 8 и запустите его на порту 6379.
3. Создайте файл настроек сервера рекордов: скопируйте `scores/.env.example` в `scores/.env` и поправьте в нём адрес Redis, если он не на этом компьютере.
4. Запустите сервер рекордов: в папке `scores` выполните `node --env-file=.env server.js`. Он ответит строкой `Scores server listening on port 3000`.
5. Отдайте папку `web/html` любым веб-сервером на порту 8080, например nginx с настройками из `web/default.conf`.
6. Откройте в браузере http://localhost:8080

## Как устроено

Страница игры обращается к серверу рекордов на том же компьютере, на порту 3000, поэтому у `scores` порт открыт наружу, а у `redis` — нет. Сервер рекордов находит хранилище по имени `redis`: так часть называется в `compose.yaml`.

Адреса сервера рекордов:

- `GET /scores` — десять лучших результатов, например `[{"name":"Аня","score":2048}]`;
- `POST /scores` с телом `{"name":"Аня","score":2048}` — записать результат; у каждого игрока в таблице остаётся лучший.

Образы `jrgames/2048-web` и `jrgames/2048-scores` собираются из папок `web` и `scores`.
